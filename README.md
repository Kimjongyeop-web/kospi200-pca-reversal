# KOSPI200 PCA Reversal

KOSPI200 구성종목의 주성분 제거 단계에 따른 기간별 단기반전 예측력 분석.
**TEAM Beta 공동 프로젝트: 김종엽·오준영·장민준·황성혁.** 공동 연구 출처를 유지합니다. 개인별 기여 범위는 원자료만으로 확정하지 않았습니다.

[최종 발표자료](reports/sprint1_beta_final.pptx)

## 방법·결과

2008~2026년 편입 이력 407종목과 시점별 편입 마스크를 사용합니다. Common252 유니버스, PCA 60/120/252일 학습, T 이전 자료로 추정한 평균·표준편차·loading으로 T일 잔차를 계산합니다. 과거 5/10/30/60일 신호와 미래 5/10/20/60일 수익률의 IC를 비교합니다.
발표자료에서 Rank IC 160개 중 155개가 양수, BH 보정 후 96개가 유의했습니다. 평균 Delta IC는 -0.00348, 유의한 양의 PCA 개선은 0/144였습니다. 비용 포함 QIC 롱숏 CAGR -6.20%, QIC 롱온리 1.12%입니다. 신호의 존재를 비용 후 수익성으로 해석하지 않습니다. 이번 정리에서 재계산하지 않은 기존 발표 결과입니다.

## 실행 구조

경로 의존성을 위해 원래 `research/` 계층을 보존했습니다. 별도 실행 폴더에 복사해 원본 분석·QC Excel 복사본을 준비합니다.
`02_build_pca_pre_signal_common252_dataset.py` → `05_build_future_log_returns_5_10_20_60.py` → `IC만들기/06_build_state_ic_train_library.py` 이후 각 파일 상단의 입력 요건을 따릅니다.
13~20번은 서로 다른 포트폴리오 실험입니다. 전체를 단일 파이프라인으로 연속 실행하지 마세요. 원본 데이터는 포함하지 않았으며 새 환경에서 전체 재실행은 검증하지 않았습니다.
